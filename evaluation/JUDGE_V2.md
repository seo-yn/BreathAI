# 채점 프로토콜 v2

기존 답변 50건을 고정하고 채점만 비교한다. 생성 모델, 검색 결과와 0.05 임계값을
변경하지 않는다. 사람 정답 라벨이 없는 자동 예비 평가다.

- `stable_judge.py`: NFKC·공백 정규화, 질문/근거/답변/모델 리비전/프롬프트별
  캐시, 엄격한 점수 형식, 근거 인용 검증 및 명시적 보수적 점수 상한.
- `judge_prompt_multipass_ko.json`: 숫자 출력 예시 없는 한국어 축별 기준. 사실성,
  답변 문체만의 공손함, 실행가능성·필수정보를 세 호출로 분리한다.
  근거 문구와 미지원 주장을 반환하도록 요구한다.
- `rejudge_saved.py`: 실제 모델 대조군과 캐시 비사용 반복 검증 후 동일 답변을
  재채점한다. 원점수와 규칙 조정 점수를 모두 저장하고 실패를 누락하지 않는다.

```powershell
python -m unittest tests.test_stable_judge tests.test_evaluation
python -m evaluation.rejudge_saved --controls-only
python -m evaluation.rejudge_saved
```

실행 결과는 기본적으로 `evaluation/results/rejudge-v2-001`에 저장한다. 이번
한국어 분리 채점 실행은 `--output evaluation/results/rejudge-v2-ko-001`을 사용했다. 기존 결과는
덮어쓰지 않는다. 캐시는 중단 후 재개 시 재사용한다. 질문·근거가 다르면 같은
답변이라도 별도 채점해야 한다. 의미상 동의어/바꿔쓰기는 자동 동일 판정하지 않는다.

## 규칙으로 적용하는 상한

- 근거 인용이 없거나 실제 입력 문서의 부분 문자열이 아니면 Accuracy 최대 2.
- Judge가 미지원 주장을 보고하거나 참고 문서가 비어 있으면 Accuracy 최대 2.
- 미지원 주장을 보고한 답변은 Actionability도 보수적으로 최대 2로 제한한다.
  일부 사실만 미지원이지만 다른 행동은 맞는 답변도 감점될 수 있다.
- 답변에 참고 문서에 없는 수치가 있으면 Accuracy·Actionability 최대 2.
  목록 번호는 제외한다. 문서에 없는 숫자가 거짓임을 증명한 것은 아니다.
- 연락처·시간 자리표시자는 Actionability·Essential 최대 2.
- 실험 지시문 복사는 Essential 최대 2.

이는 보수적 근거 확인 정책이지 검증된 진실 판정기가 아니다. 정확한 인용도 논리적
뒷받침을 보장하지 않으며, 원문에 없는 올바른 수치나 다른 수치 표현도 감점될 수 있다.
따라서 `judge_audit.raw_scores`, `scores`, `policy_flags`를 구분해 해석해야 한다.
새 점수와 이전 점수의 차이는 채점 규칙 변경 효과이며 모델 성능 변화가 아니다.

초기 단일 호출 보완안은 무례한 정답의 사실성까지 낮춰 대조군에서 실패했다.
해당 결과는 `rejudge-v2-001`에 보존했으며 성능 비교로 사용하지 않는다.
분리 채점은 공손하지만 틀린 답변과 무례하지만 맞는 답변을 모두 대조군에 포함한다.

2026-10-12 실제 재시험 결과: 영어 분리 채점과 한국어 분리 채점 모두 대조군 실패.
한국어 정상 답변은 정확성 4, 공손함 3, 실행가능성 4, 필수정보 5였으며,
공손한 오답은 1/3/1/1이었다. 공손함의 축 분리가 충분하지 않아 50건 재채점은
실행하지 않았다. 이후 정상 답변의 공손함도 통과 조건에 추가했다.
실패 기준을 완화하거나 미실행 점수를 채우지 않았다.

## 적용 범위

운영 생성기/Refine 자기 평가 코드는 변경하지 않았다. 이 구현은 비교표의 최종 평가를
보완하는 별도 실험 경로다. 같은 Qwen 계열의 작은 Judge 편향, 잘못된 표준 질문,
불완전한 참조 근거는 남아 있으며 사람 평가를 대체하지 않는다.
