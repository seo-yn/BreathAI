# 분석 업로드 파일 형식

`POST /api/v1/dashboard/analyze/upload`의 multipart `file`은 `.csv`와 `.xlsx`를 받습니다.
확장자는 대소문자를 구분하지 않으며 브라우저의 MIME 타입에는 의존하지 않습니다.

- CSV는 기존 인코딩과 내용을 유지해 AI `/pipeline`으로 전달합니다.
- XLSX는 첫 번째 시트를 UTF-8 CSV로 변환해 `.csv` 파일명으로 전달합니다.
  첫 번째 행은 헤더여야 하며 CSV와 동일한 열 이름과 구조를 사용해야 합니다.
  쉼표, 따옴표, 셀 내부 줄바꿈은 CSV 이스케이프 처리합니다.
  표시 형식(예: 숫자의 앞자리 0)을 유지하고 빈 행은 건너뜁니다.
  다른 시트는 분석하지 않습니다.
- 이력과 응답 파일명, 크기, 중복 검사 해시는 원본 업로드 기준입니다.
- 빈 파일, 손상되거나 빈 XLSX는 `400 / D-004`, 지원하지 않는 확장자는
  `400 / D-005`를 반환합니다. `.xls`는 지원하지 않습니다.

업로드 파일은 요청 처리 중 메모리로 읽어 비동기 전송 시 임시 업로드 파일의
수명에 의존하지 않습니다. 분석 옵션과 multipart 필드 이름은 기존과 같습니다.

이 저장소의 develop에는 AI `/pipeline` 수신 구현과 프런트엔드가 없습니다.
AI 서버의 기존 CSV 열 규칙은 그대로 적용되며 실제 AI 서버와의 통합 검증은 별도로 필요합니다.
